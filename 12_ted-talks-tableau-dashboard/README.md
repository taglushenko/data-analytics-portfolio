# Анализ TED Talks в Tableau

## Описание проекта

TED Talks представляет собой крупнейшую коллекцию публичных выступлений на научные, технологические, культурные и социальные темы. Цель проекта состояла в исследовании истории TED-конференций, популярных тематик, активности авторов и особенностей различных форматов мероприятий с помощью интерактивных дашбордов Tableau.

В рамках проекта был подготовлен набор связанных дашбордов, позволяющих анализировать выступления по странам, тематикам, авторам и форматам конференций.

## Структура дашбордов

### 1. История выступлений
Анализ географии конференций, динамики выступлений по годам и изменения популярности тематик.
- **Выступления по странам** — карта с долей выступлений по каждой стране
- **Выступления по годам** — диаграмма с областями, разбивка по топ-7 тематикам
- **Процент выступлений по тематикам** — стековая диаграмма с областями (% от общего)

### 2. Тематики выступлений
Исследование распределения тематик, различий между странами, а также связи между реакцией аудитории, длительностью выступлений и просмотрами.
- **Выступления по тематике** — круговая диаграмма (топ-7 + «Другие»), tooltip с гистограммами
- **Тематики и страны** — таблица с подсветкой: % выступлений по теме в топ-3 странах
- **Аплодисменты по тематикам** — диаграмма рассеяния по каждому выступлению
- **Смех по тематикам** — диаграмма рассеяния по каждому выступлению
- **Связь длительности с просмотрами** — scatter plot по каждому выступлению

### 3. Авторы выступлений
Анализ областей деятельности авторов, распределения числа выступлений и наиболее популярных спикеров.
- **Области деятельности авторов** — пузырьковая диаграмма (top-N, управляется параметром-слайдером)
- **Распределение числа выступлений** — столбчатая диаграмма
- **Авторы по числу выступлений** — таблица с сортировкой
- **Выступления и число просмотров** — таблица с сортировкой

### 4. Форматы TED-конференций
Сравнение различных форматов TED по популярности и просмотрам, а также анализ изменения тематической структуры во времени.
- **Динамика категорий по годам** — линейный график с разбивкой по 8 форматам конференций (TEDx, TED Main, TEDGlobal, TEDMED, TEDSalon, TEDWomen, TEDYouth, TED@Corporate)
- **Просмотры по форматам** — сравнение среднего числа просмотров между форматами
- **Состав тематики «Другие» в 2019–2021 годах** — диаграмма с областями, показывающая как менялся состав менее популярных тематик
